# Review of the open Koma pull requests

- Updated: 2026-10-03
- Scope: roman-n1/koma pull requests #52–65, originally stacked in that order.
- Remote execution was authorized by Roman on 2026-10-03. #52–54 are merged; all remaining
  branches contain the review fixes, published without force pushes. Each remaining merge
  requires all six GitHub checks to succeed on its current head.

The review found four reproducible bridge failures and an inconsistent close assertion in the
core soak test. The corrected complete stack passes JVM, Android host, iOS Simulator, JS browser
and Wasm browser tests, API checks, the dependency graph check and iOS device compilation.
There is no release or tag change in this work.

## Result compared with upstream 4.0.0

The fork adds six optional modules: statecharts and MachineStore, observability/journal,
time travel and replay, the Compose inspector, the machine test kit, and machine Compose
helpers. It also carries core stability fixes, input correlation and observation hooks,
handler metadata, awaitIdle and long-lived subscriptions. Companion changes include
recorder event cursors, pending-work assertions, ViewStore.select and fixes to Compose,
logging and message delivery. API dumps and the dependency graph check now run in CI.

The exact core and companion differences, their regression tests, and their upstream
disposition are recorded in the [divergence inventory](../design/2026-09-28-statechart-roadmap.md#divergence-inventory-vs-upstream-400).
The additive modules do not imply upstream acceptance. Seven upstream change branches
are prepared; U3 depends on U2. This review submits no upstream issues or PRs, and publishes
no Maven release. Fork coordinates remain io.github.roman-n1 at 5.0.0-alpha.1.

## Reproduced failures

Four new deterministic tests fail on the original tip, 2659ac2, and pass on the corrected tip:

- MachineGroupTest.anImmediateReceiver_isJournaledAfterItsSend: an immediate receiver appeared
  in the journal before its sender.
- MachineGroupTest.aRoutedEffect_tracksEachReceiverUntilItDecidesOrCloses: a second destination
  overwrote the first delivery in the in-flight map.
- GroupCloseJvmTest.closeWaitsForTheCommittedObserverBeforeDroppingMessages: close dropped an
  input whose committed observer had not finished.
- GroupReplaySessionTest.anImmediateReply_isRecordedAfterItsRequest_evenWhenTheBridgeObserverIsFirst:
  replay reported ReceivedBeforeSent and ReplyWithoutRequest when the bridge observer preceded
  the group recorder.

The original source plus only these test changes is preserved in the temporary
koma-pr-repro checkout. Its expected-failure log is build/pr-review/before-fixes.log.
